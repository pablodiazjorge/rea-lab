# Private process log in _docs-internal

Status: accepted

`_docs-internal/` is ignored by git, and `scripts/check.mjs` fails if it ever stops being ignored. It holds the initial plan, the process log, raw notes with local paths, measurements, contribution records, phase reviews and post drafts, so the author can follow the whole process while the public repository stays clean. Anything worth publishing is sanitised and moved to `docs/` or `writeups/`.
