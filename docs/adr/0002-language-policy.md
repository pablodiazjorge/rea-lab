# English by default, bilingual only where people read

Status: accepted

Code, comments, identifiers, file names, script output, ADRs, `AGENTS.md`, commits (Conventional Commits), issues and pull requests are written in English. READMEs, guides and writeups are bilingual: `README.md` in English and `README.es.md` in Spanish, kept in sync by `scripts/check.mjs`, which also enforces the Spanish style rules (RAE, no em dash, no middle dot as a separator). Translating text that nobody reads in Spanish would be maintenance without return.
