# How the lab contributes to rea

Status: accepted

Before coding, claim the issue with a short proposal and wait for the maintainer. Then send a minimal pull request with tests, the full template, only commands that were actually run and evidence from real Windows. Keep one pull request open at a time. A pull request closed as superseded with credit counts as a success, and non-code contributions (Windows lane reports, measurements) come first, because the lab's advantage is a Windows machine where rea works.
