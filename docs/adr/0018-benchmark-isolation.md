# Benchmark isolation

Status: proposed (F4), to be accepted after the pilot; amended for study 3

Each run gets a fresh folder outside the repository, under the benchmark home (`REA_LAB_BENCH_HOME`, by default `%LOCALAPPDATA%\rea-lab-bench`), holding only the target, renamed to `target.exe` so the file name gives nothing away, and an empty `CLAUDE_CONFIG_DIR` created for that run. Authentication is a long-lived token from `claude setup-token`, passed only to the child process in `CLAUDE_CODE_OAUTH_TOKEN`; no credential file is copied, and every inherited `CLAUDE*`, `ANTHROPIC_*`, `REA_*`, `GHIDRA_*` and `JAVA_HOME` variable is dropped. Claude Code runs with `--print --output-format stream-json --verbose --no-session-persistence --setting-sources user --strict-mcp-config`, a fixed `--model` and `--effort`, and `--permission-mode dontAsk`, so anything the run's own settings do not allow is denied instead of prompting. The run's permissions go in a settings file passed with `--settings`, because print mode ignores permission rules from settings files in an untrusted folder. Condition A gets Read, Grep, Glob and Bash limited to `llvm-readobj`, `llvm-objdump`, `llvm-strings`, `llvm-nm` and a few text filters, with no interpreter, so the target cannot be run. Condition B adds rea through an MCP configuration generated for the run, with rea's temporary folders inside the run folder. Condition C adds rea's skill, copied into the run's configuration folder as `rea setup` would. No user plugin, `CLAUDE.md`, memory or skill reaches a run. Claude Code's init event lists the plugins, skills and MCP servers that actually loaded, and a run whose list differs from its condition is flagged in the report. Plugins shipped inside the pinned Claude Code (source `@builtin`) are part of the client and load in every condition. The harness runs a pinned Claude Code (an exact dev dependency, or the executable in `REA_LAB_BENCH_CLAUDE`), records its version in every run and refuses to start a study whose version differs from the preregistered one. On timeout the whole process tree, including the MCP server and Ghidra's JVM, is killed with `taskkill /T /F`. Graders are deterministic, with no LLM judge. `total_cost_usd` is reported as equivalent cost, not as money spent.

Amended for study 3: in real-software sets ([ADR 0024](0024-real-software-tasks.md)) a run may also read Claude Code's own `projects` folder inside its configuration directory, where the client saves tool outputs too large to return inline. In study 2 those reads were denied and flagged as paths outside the work folder, which cut the agent off from its own results. Older sets keep the original rule, so their published grading does not change.
