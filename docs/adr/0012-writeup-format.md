# Writeup format

Status: proposed (F3)

Each writeup lives in `writeups/YYYY-MM-slug/` with `README.md`, `README.es.md`, `evidence.json`, `provenance.json` and `media/`. It lists findings with their `evidence_id`, confidence and authority, plus open unknowns, agent mistakes, cost and how to reproduce the session, following rea's observed / derived / inferred model so anyone can verify the claims.
