# Writeup format

Status: accepted (F3), amended for the benchmark studies

Each writeup lives in `writeups/YYYY-MM-slug/` with `README.md`, `README.es.md`, `evidence.json`, `provenance.json` and `media/`. It lists findings with their `evidence_id`, confidence and authority, plus open unknowns, agent mistakes, cost and how to reproduce the session, following rea's observed / derived / inferred model so anyone can verify the claims.

Amended for the benchmark studies: a study writeup (`writeups/2026-10-study-N/`) has only `README.md` and `README.es.md`; its preregistration, data and report live under `bench/`. Investigation writeups also keep each session plan as `session-plan*.json`, and `media/` exists only when a writeup has images.
